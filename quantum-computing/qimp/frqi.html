Flexible Representation of Quantum Images (FRQI)

Le et. al, 2011's FRQI significantly advances the field of quantum image processing. Like qubit lattice, superposition is used to store colour on qubits. Unlike qubit lattice entanglement is also utilised, significantly reducing the number of qubits necessary for large images.

Entangling colour and pixel position

Encoding a square, greyscale image with side length n2 in the FRQI format requires 2n+1 qubits. The FRQI state can be thought of as containing two groups of qubits, colour encoding and positional encoding. To observe this we may split our initial state:

0 ⊗ 02n

As with many quantum algorithms, the Hadamard gate is used to prepare the state. The transform H=I⊗H⊗2n is used to place all positional qubits in maximal superposition, producing the state H.

H 02n+1= 1#2n 0 ⊗ 2n-1~i=0 i= H

Here i represents the binary representation of the value i expressed with the basis states of the qubit string. It is clear to see possible value of i, that is every pixel index within the image, has an equal probability of being measured.

H is actually a valid FRQI state without any colour encoded. Each time the state is measured the value of the locational qubits is interpretted as the location within the image of the colour returned by the colour encoding qubit. Our current state, in all possible cases, returns a colour value of 0, meaning that the H encodes a uniform, blank image.

As with qubit lattice, colour is encoded using the application of a rotational gate. However, a lone RY applied the colour encoding qubit is insufficient as it would change the colour of the entire image simulteneously.

To resolve this the colour encoding RY gate is controlled dependent on location. With the use of projectors, we may construct an operator Rk that encodes the colour θk dependent on the locational qubits being in a target state k. This process entangles the colour encoding qubit with the locational qubit string.

Rk = RY(θk) ⊗ kk+ I ⊗ 22n-1~j=0, j≠k jj

The action of this operator on the H is made clear when the reader considers the orthogonality condition on the locational qubits.

Applying the θk for all pixel locations within in image produces a complete FRQI state. Each possible locational qubit string value is entangled with the colour associated with that location, ensuring colour and positional information are correctly matched. The full FRQI state is thus:

FRQI = 1#2n 22n-1~i=0 (cos θi 0+ sin θi 1) ⊗ i

To encode a full RGBa image 4 colour (or more accurately 'channel') encoding qubits may be used, for a total image size of 2n+4 qubits. Alternatively, 2 colour encoding qubits may also be placed in superposition using a Hadamard gate, and used as additional control values when encoding colour. This approach, described by Sun et. al, 2011 reduces the number of qubits necessary to 2n+3.

Retrieval

Retrieving an FRQI image from its quantum state is costly:

  • Each measurement returns information concerning a random pixel position with equal probability.
  • Each measurement at a pixel location does not give us an exact value, it only improves our knowledge of the colour at that position.
  • Encoding an FRQI state is costly, requiring many multiple-control gates.
  • Image dimensions that are not powers of 2 result in meaningless locations outside the original image being returned.

The value of FRQI clearly is not in efficient retrieval. Instead, the entangled coordinate system allows for certain image manipulations to be performed incredibly efficiently once the image is encoded.

For example, to invert the colour of the entire image only a single X gate applied to the colour encoding qubit is necessary. Alternatively by applying X gates to the locational qubits encoding the x position the entire image may be efficiently flipped horizontally.

Efficient full image manipulations are a strength of the FRQI state, leading to its widespread use for QIMP tasks following its introduction. The choice of encoding state selected by a quantum developer is crucial as only certain manipulations may be performed efficiently on a given state.
