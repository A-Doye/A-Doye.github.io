Transforming quantum images

So far this section has looked at how to encode images into quantum states. Encoding alone is not useful; storage of images is already easily achieved on classical devices.

Instead, encoding methods much be chosen with how the image is to be used once it is encoded in mind. By selecting an appropriate encoding method one can significantly reduce the number of gates necessary to achieve desired alterations to an image.

Simple transformations

Suppose we wish to invert the colour of a black and white image. In the classical bitmap case this would require updating every pixel value with a new, inverted value. The case for an image encoded using Qubit Lattice encoding is similar. Each qubit in the image requires updating with the application of a single NOT gate. This operation is shallow in circuit depth, but requires the application of many gates.

Suppose instead the image is now encoded using an FRQI state. It is now possible to invert the colour of the entire state using a single NOT gate! By applying a single NOT gate to the previously described colour encoding qubit the colour stored in all pixel locations are inverted simulteneously.

X⊗I⊗2nFRQI = 1#2n 22n-1~i=0 (cos θi X0+ sin θi X1) ⊗ I⊗2ni

= 1#2n 22n-1~i=0 (sin θi 0+ cos θi 1) ⊗ i

It is easily observed that the colour encoding amplitudes associated with the 0 and 1 states have been swapped, constituting a colour inversion. Application of a NOT gate to each of the colour encoding qubits of the NEQR state performs a similarly efficient colour inversion.

Another manipulation that may be performed efficiently within the quantum realm is the reflection of an image.

This can be achieved on FRQI-like states with the application of NOT gates to locational encoding qubits. Suppose we wish to reflect the image horizontally. First, the state is rewritten to separate the locational qubits of the FRQI state into x and y positional encoding. A NOT gate is then applied to all x postional encoding qubits.

I⊗X⊗n ⊗I⊗n FRQI = 1#2n 2n-1~x=0 2n-1~y=0 (cos θxy I0+ sin θxy I1) ⊗ X⊗nx I⊗ny

= 1#2n 2n-1~x=0 2n-1~y=0 (cos θxy 0+ sin θxy 1) ⊗ ~x y

Where ~x denotes inversion of the x qubitstring. Inversion of the x has the effect of producing a reflected image when it is recovered. This process is also efficient when compared to its classical counterpart.
