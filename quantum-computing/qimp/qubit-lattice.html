Qubit Lattice

Storing Colour

How can a quantum state be used to store colour? Classically a bitstrings store values representing colour. Similarly, a qubitstring of computational basis states could be used to encode colour, but using basis states fails to leverage the quantumness of qubits.

Alternatively quantum superposition may be used. Suppose we have some colour value, C, stored in an 8-bit string that we wish to encode on a qubit. C has a lower and upper bound, so, with some conversion function F, we may express it as an angle:

F(C [0:255]) → θC [0:π]

Converting our colour into an angular form is useful as it may now be encoded onto a quantum state using a rotational gate. Observe how an RY gate encodes different colour values onto a qubit initialised in the 0 state:

C0= 0, F(C0) = 0 = θ0 → RY(θ0)0 = 0

C128= 128, F(C128) ≈ π#2 = θπ/2 → RY(θπ/2)0 = 1#2 (0+1)

C255= 255, F(C255) = π = θπ → RX(θπ)0 = 1

Or more generally a colour encoding qubit ψ can be created:

RX(θC)0 = cos θ#2 0+ sin θ#2 1 = ψ

Retrieval is achieved with repeated measurement of the colour state. Tones at the extremities of the colour range are deterministc, and can be retrieved from the quantum state with absolute accuracy. Intermediate values rely on finding the average result over multiple measurements of the image state to approximate the original value. The more a colour qubit is measured the more confident we can be in the accuracy of the retrieved colour, though perfect retrieval cannot be guarenteed.

Building an image

Venegas-Andraca, 2005 expands this colour system to store an entire image. The process is relatively simple; a 2D matrix of colour encoding qubits, each encoded with a coresponding colour value from a target image, creates a quantum copy of the image. The above method encodes a single colour value onto a qubit, so in the case of a colour image each RGB value at a pixel location requires its own qubit to encode.

One 2D matrix copy is enough to start considering approaches for manipulating the image within the quantum computer. When considering the storage space of the entire image however, it may be more useful to imagine the image as a 3D matrix built from layers of 2D copies of the image.

Evaluation

Representing quantum images using a qubit lattice is a simplistic approach. A one-to-one pixel to qubit ratio is easily understood, and quick to implement on quantum devices.

A notable advantage of this simplisity is the shallowness of circuit depth necessary for each encoding cycle. Using a single rotational gate on each qubit reduces the impact of noise during encoding, which is valuable during the NISQ era.

This comes at the cost of space inefficiency, with space complexity O(n). Other quantum methods are far more efficient in this regard.
