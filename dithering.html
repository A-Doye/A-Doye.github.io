What is dithering?

Dithering is a method to reduce the colour depth of an image whilst retaining a higher degree of perceived colour depth. This means that a dithered image can be created with a far smaller colour palette than a typical digital image, whilst still looking good. This is possible because the human eye can perceive groups close groups of different colours as one entirely new colour, not present in the palette.

Because dithering uses less colours than a full quality image it can reduce the size of image files. This was particularly useful when storage space was limited or internet connections slow. Dithering is less used today, but remains popular as a stylistic choice in video games such as Obra Dinn and Highfleet.

How can images be dithered?

Image dithering can be split into two types of algorithm, ordered and error diffusion.

Ordered dithering

Ordered dithering uses a matrix of thresholds to determine the colour at a given pixel location. Suppose we want to convert a greyscale image to have a bit depth of just one, representing either black or white. At each pixel location in the image the colour of the pixel is compared to its corresponding threshold in the threshold matrix. If the value exceeds the threshold, the pixel is made white, else black. The threshold matrix, usually a square of size 4x4 to 16x16, is duplicated to cover the entire image.

Ordered dithering is easier to implement and produces a distinctive visual effect. Unlike error diffusion algorithms, ordered dithering does not require pixels to share knowledge which can allow for fast implementation through parallel processing, such as through graphics cards.

Error-diffusion dithering

Typically, error diffusing algorithms work pixel by pixel, starting in a corner of the image. They take the colour value of a pixel and assign it the closest new colour in a given limited palette. Once this colour is found the error value produced by this assignment is calculated. The error value quantifies the difference between the original pixel colour and its newly assigned value. The error is then diffused (distributed) to nearby pixels using a kernel. Pixels that are not yet dithered receive a portion of the error value according to the kernel. Most kernels ensure 100% of the error value is passed on in small proportions to a group of nearby pixels. Once the error has been diffused, the algorithm moves to dither the next pixel, finding the nearest colour to the colour of the pixel plus any accumulated error. The kernel is applied line by line until the image is entirely dithered.

Error-diffusion generally produces higher quality results than ordered dithering, but can be more intensive. Choice of a good kernel and a reasonably sized colour palette can produce images with colour reduction that is not imediately noticeable. Floyd-Steinberg, Stucki, Burkes and Sierra are examples of error-diffusion algorithms.
